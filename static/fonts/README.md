# Departure Mono

Monospaced pixel typeface by Helena Zhang and Tobias Fried.
Source: https://departuremono.com — https://github.com/rektdeckard/departure-mono

`LICENSE.txt` is the upstream licence, copied verbatim from that repository.

Bundled here rather than fetched from a CDN so the panel and the phone surface
keep working with no network, which is the whole premise of the extension.
