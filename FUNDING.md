# Funding

If this project saved you time on stage, in the studio, or while prototyping, consider supporting development.

Ableton RC Surface is **licensed under the PolyForm Noncommercial 1.0.0**
and free to install for noncommercial use. The code is open source, the
`.ablx` is free to install, and there is no Pro tier. Donations fund the next
round of work, not gate existing features.

## Where donations go

- Future features (offline MediaPipe bundle, WebRTC multi-phone, WebMIDI)
- New control templates (Drum Rack, Sampler, Wavetable)
- Hardware testing on real stage rigs
- Maintenance time for the bugfix release train (0.5.8.x)

## How to fund

- **Gumroad (pay what you want, suggested R$25, minimum R$0)** — link published in the project README and on the release page. The default is R$0 so cost is never a barrier. R$25 is anchored to "one hour of dev time saved on setup".
- **Direct support** — only trust funding links published in the official repository (this repo's README and release notes). Do not send money to personal accounts advertised elsewhere.

## Why this matters

This project was built and tested entirely by one operator + AI agents on commodity gear. Funds keep the lights on while new generations of mobile browser APIs land. Reaching more musicians and getting honest feedback matters more than maximizing the donation ask.

If you can't pay: starring the repo, filing issues with reproduction steps, and sharing screenshots or clips on social media is just as useful. The goal is reach, not extraction.
