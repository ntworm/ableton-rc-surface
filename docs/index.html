Ableton
RC Surface

A phone browser, turned into a controller surface for Ableton Live. The surface is served from your own machine over local HTTPS; the phone connects to it over the same network. Nothing is installed on the phone.

Held in landscape. Seven pages, twelve pads, six knobs, six faders, two XY pads, three sensor inputs. This sheet is the operator's reference for build 0.6.0.

└──────────────────────────────────────────┘
▼ CONTROL, OUTBOUND      ◀ STATE, INBOUND

Both directions run at 30 Hz and both stay on the LAN. Outbound, a touch becomes a socket frame, the server resolves it against the curve and the current snapshot, and it leaves as OSC. Inbound carries tempo, beat and transport state, plus the current values of mapped parameters, so a fader moved in Live moves on the phone. Latency depends on router, distance, interference and host load, so no single figure applies. Measure on the target network before relying on it in performance.

2.1 · Clock source

ModeNeedsWhat you get
AbletonOSCAbletonOSCBeat-accurate. Transport metronome, subdivisions, swing, phase.
SDKnothingBPM simulator off Live's tempo. No beat phase.
FreenothingInternal clock. LFOs and stutters are not locked to Live’s tempo.

AbletonOSC is needed only for Deep Sync. Without it the surface still works — pads, knobs, faders, sensors, mapping and snapshots are unaffected. It installs separately, is added in Live as a Control Surface, and requires UDP 11000 out and 11001 in to be free.

Long-press SYNC on the phone for Deep Sync Settings: clock source, subdivisions, phase offsets, swing, and the shape used by LFOs and stutters. The header button itself only toggles SYNC and FREE; the three-state SYNCED / SDK / FREE readout lives inside the transport overlay behind TRN.

Sends is the transport a row uses: OSC reaches Live through AbletonOSC, MIDI is a note the host receives, local never leaves the phone. Every OSC row is assigned in MAP mode — row 0F. Rows 10 and 11 sit in the header and are reachable from every page, which is why their Page column reads header rather than a tab.

4.2

The header — present on every page

BPM

Live's tempo, mirrored. Read-only.

Transport

Previous locator, play and pause, next locator. Controls Live's transport from the phone.

TRN

Full-screen overlay: PLAY, STOP, PREV, NEXT, REFRESH, a locator list and a search. Carries the SYNCED / SDK / FREE readout. Flashes green on beat 1, blue on the others.

MAP

Opens the mapping picker as an overlay on the current page. It has no tab of its own.

SYNC

A two-state toggle: the button itself reads SYNC or FREE. Long-press for Deep Sync Settings. See 2.1.

Settings

Opens Deep Sync Settings directly, without the long-press.

CALIBRATE

Re-zeroes motion and orientation to the phone’s current position.

STAGE

Locks the surface to the current page, preventing accidental page changes during performance.

Status

Link state and the phone's name. Tap to rename.

4.1

What each one does

Pads & PERF UTIL
Twelve pads with four behaviours — release, hold, toggle, burst — plus the PERF UTIL column: CAP to capture, direct snapshot slots 1–4 to recall, and OFF to exit. These four recall directly, without the transition applied to the SNP morph slots.
Knobs, faders, MIX
A mixer-style page for common Live controls, and a dedicated MIX tab on the phone with six mappable knobs and six mappable faders.
XY pads
Two-axis controls, typically assigned to filters, sends or macros. X and Y are exposed as separate mappable channels in the phone editor, so one gesture drives two unrelated parameters.
MAP mode
Select a highlighted control on the phone and bind it. The target picker is grouped by Song / Main / Master, normal tracks, return tracks, devices, and parameters. Tap Selected in Live to query the host and pre-fill the search.
Sensors
Motion, orientation, and microphone analysis are built in. Camera hand tracking is single-hand by design, with five built-in detectors: open, fist, pinch, victory, fingers.
Snapshots
Eight morphable slots for interpolating between controller states, plus the four direct capture and recall slots on the PERF UTIL column. Mapped Live values follow the transition while the morph runs. Transition time is adjustable from 0.1 s to 5.0 s.
MIDI trigger notes
Map a phone control to a note on a MIDI track. The bundled RC-Midi-Receiver.amxd is reused if it is already on the track, and falls back to manual insert on failure. Pads, LFOs, stutters, XY axes, knobs and faders all support trigger-note mappings.
TRN transport
A full-screen transport overlay reached from the header. Detailed in 4.2.
Deep Sync
Long-press SYNC for clock source, subdivisions, phase offsets, swing, and the shapes used by LFOs and stutters. See 2.1.
2D curve preview
The mapping editor includes a 2D response canvas with a live input-against-output dot, shown while adjusting range and curve. Idle value and per-control rate are configurable.
Local HTTPS
A self-signed certificate is generated on first launch so the phone browser will grant camera and microphone permissions. Current LAN IPs are written into the certificate's SAN list.

Installation — from download to a mapped parameter

Steps 01 to 03 establish the link shown in 2.0. Nothing responds until the phone is connected.

Clip 1 Install and first pairing, narrated mp4

Install the extension

Download Ableton-RC-Surface-0.6.0.ablx. Double-click it and Ableton Live prompts to install it under User Library / Extensions. Restart Live if it was already running.

If the Extensions menu does not appear, check that the Live 12.4.5+ Suite Extensions host is enabled, then restart Live.

Open the panel

Inside Live, open Extensions → Ableton RC Surface → Show panel. The panel shows a Performance QR code and the local connection status. The bridge picks an available port automatically, so the URL is not fixed between runs.

Connect the phone

Scan the Performance QR code. Accept the self-signed HTTPS certificate warning once. The QR encodes the current URL. Hold the phone in landscape; portrait shows an orientation notice instead of the surface.

Pick a pad mode

The twelve pads take their behaviour from the mode bar: A momentary, B hold, C toggle, D burst. Move between PERF, MIX, SNP, SNS, AUD and VID to reach performance controls, knobs and faders, snapshots, sensors, audio and vision.

Arm the sensors

Enable Motion and orientation, Audio microphone analysis, or Vision single-hand tracking as needed. The browser asks for permission locally. Raw camera and microphone streams are never sent anywhere — only numeric control values leave the phone.

Map a control to Live

Tap MAP on the phone, select a highlighted control, then bind it to a Live parameter or to a MIDI trigger note. The picker groups Song, Main and Master, normal tracks, return tracks, devices and parameters, so the target context stays visible. Trigger notes use the bundled RC-Midi-Receiver.amxd.

Optional: Deep Sync

Install AbletonOSC separately and add it in Live as a Control Surface, keeping UDP 11000 and 11001 free. Long-press SYNC on the phone to pick the clock source. Without it the surface runs on the SDK BPM simulator or its own internal clock — see 2.1.

Troubleshooting

Phone cannot find the host

Same Wi-Fi. Live allowed through the firewall. Rescan the current QR.

The port changes between runs, so an old URL will not work.

AbletonOSC not detected

Install it separately as a Live Control Surface.

Keep UDP 11000 and 11001 free. Only Deep Sync needs it.

Vision will not start

Accept the certificate, grant camera, reload.

All three are required, in that order.

Audio is silent

Grant microphone, then tap the audio control again.

Browsers require a user gesture before capture starts.

No Extensions menu in Live

Check the Live 12.4.5+ Suite Extensions host is enabled, then restart Live.

Frequently asked — setup, limits, privacy

Which Live versions?

12.4.5+ Suite (Beta).

It is built on Live's native Extensions SDK. Live 11 and standard editions have no Extensions host.

Android and iOS?

iOS 15.4+ Safari, or Chromium on Android.

iOS 14.5 and below cannot get past local self-signed certificate warnings.

Does it need internet?

No. Everything runs on your local network.

The MediaPipe hand-tracking runtime ships with the extension and is served locally.

Can I map from the phone?

Yes. MAP, pick a control, then Bind or Trigger Note.

The picker groups Song, Main and Master, tracks, returns, devices and parameters.

What about latency?

30 Hz both ways over local Wi-Fi. No universal number.

Router, distance, interference and host load all affect it. Measure on the target network.

Camera and microphone?

Processed inside the phone's browser. Never uploaded.

Only numeric control values reach Live, over the local WebSocket.

Official Ableton product?

No. Independent and source-available.

Not affiliated with, sponsored by, or endorsed by Ableton AG.

Is AbletonOSC required?

Only for Deep Sync.

Without it the controller runs on the SDK BPM simulator or its own internal clock.

How mature is it?

v0.6.0. tsc --noEmit clean; the production build produces a working .ablx.

Smoke-tested in Live 12.4.5+ Suite (Beta). Full validation on physical iOS and Android devices is outstanding.
