How is this different?

Existing mobile controllers fall into a few categories: native apps with OSC bridges, or hardware. RC Bridge takes a different path — browser-based, MIDI native, sensor-aware. Here's the shape of the difference.

Ableton RC Bridge Typical mobile controller
Install on phone Browser, no install Native app, paid
Price Free, MIT, donations welcome $9.99–14.99 typical
Protocol MIDI native (Extensions SDK) OSC + bridge required
DAW support Live 12.4.5+ Suite Cross-DAW
Sensor fusion First-class (gyro / accel / audio / camera) Basic gyro only
Simultaneous clients Performance + admin One client
Updates Shipped instantly via .ablx App store review cycle
Source code MIT, auditable Closed source

If you need cross-DAW support or a polished touch-only controller, existing native apps are the more mature choice. RC Bridge is for producers who want their phone's sensors as first-class inputs and prefer open tooling.

Install in 60 seconds

Three steps. No terminal. No build. No phone app.

  1. Install the extension

    Download Ableton-RC-Bridge-x.y.z.ablx from the Releases page. Double-click it. Live will offer to install it under User Library / Extensions. Click Install.

  2. Open the panel

    In Live, open Extensions → Ableton RC Bridge → Show panel. Two QR codes appear: Performance (pads/knobs/sensors) and Mix (structure-aware mobile mixer). Scan the Performance QR with your phone.

  3. Start playing

    Your phone opens a browser with the controller surface. The browser warns that the certificate is not trusted — this is expected for self-signed certs. Accept once, the phone remembers, and you're in.
